# The Law Student’s Lexicon — Build 43

[Open the web app](https://illteachyoutoo00-collab.github.io/Law-Student-s-Lexicon/) · [Android APK and QR code](https://illteachyoutoo00-collab.github.io/Law-Student-s-Lexicon/download.html)

Web and Android version 1.4.25+43 include English–Mongolian student problem reporting. Reports are delivered to the author’s private GitHub repository through the secure reporting API. Students do not need GitHub accounts.

All 652 entries and their dictionary assets are preserved. The signed Android APK updates the original Build 42 installation. The download-page QR code continues to work when later APK versions are published.

This repository contains compiled public web files and Android release downloads. Private Flutter source and signing credentials are kept separately.
